# Extend Strategic Blueprint to all public routes

Type: task
Status: resolved

## Request

Apply the selected Strategic Blueprint design to all other public pages, excluding `/admin/**`.

## Answer

All public routes use the Blueprint header, footer, typography, colors, and navigation. Interior pages share a dark hero and grid-based content treatment; article, products, forms, legal copy, and error states receive route-appropriate styling. Public breadcrumbs and bilingual copy remain available. Admin routes keep the existing admin shell.
